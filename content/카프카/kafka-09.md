# 1. 카프카 커넥트 소개
![[Pasted image 20260726111759.png|508]]
카프카 오픈소스에 포함된 툴로, 데이터 파이프라인을 만들 때 반복 작업을 줄이고 효율적으로 전송하기 위한 애플리케이션. 
특정 작업 형태를 템플릿으로 만들어 둔 커넥터(connector)를 실행함으로써 반복 작업을 줄인다

### 소스 커넥터, 싱크 커넥터
```mermaid
graph LR
    SRCAPP["소스 애플리케이션/파일<br/>(MySQL·S3·MongoDB…)"] -->|"소스 커넥터<br/>(프로듀서 역할)"| K["🐘 카프카<br/>토픽"]
    K -->|"싱크 커넥터<br/>(컨슈머 역할)"| SINKAPP["싱크 애플리케이션/파일<br/>(Elasticsearch·JDBC…)"]
```

|       | 소스 커넥터(source)                     | 싱크 커넥터(sink)                             |
| ----- | -------------------------------------- | -------------------------------------------- |
| 방향    | 외부 → 카프카 토픽                            | 카프카 토픽 → 외부                                  |
| 맡는 역할 | 프로듀서                                   | 컨슈머                                          |
| 예     | file source connector(파일→토픽), MySQL→토픽 | file sink connector(토픽→파일), 토픽→Elasticsearch |

### 커넥트 내부 구조
![[Pasted image 20260726112021.png|402]]
커넥터 생성 명령을 내리면 -> 커넥트는 커넥터와 태스크 생성
커넥터: 태스크 관리
태스크: 커넥터에 종속되는 개념, 실질적인 데이터 처리

커넥트는 프로세스, 커넥터는 그 안에서 태스크를 관리하는 스레드

# 2. 커넥터
### 플러그인
| 종류           | 내용                                                                                                        |
| ------------ | --------------------------------------------------------------------------------------------------------- |
| **기본 플러그인**  | 카프카 **2.6**에 포함 — **미러메이커2**(클러스터 간 토픽 미러링), **파일 소스**·**파일 싱크** 커넥터                                      |
| **오픈소스 커넥터** | 이미 공개된 커넥터 **jar를 다운로드**해 씀. HDFS·AWS S3·JDBC·엘라스틱서치 등 **100개+**. → **컨플루언트 허브**(`confluent.io/hub`)에서 검색 |
| **커스텀 커넥터**  | 라이선스/요구사항이 안 맞으면 **직접 개발**(→ G절)                                                                          |

### 컨버터, 트랜스폼 (커넥터 옵션)
선택적으로 붙이는 기능

| 기능                  | 하는 일                               | 종류                                                               |
| ------------------- | ---------------------------------- | ---------------------------------------------------------------- |
| **컨버터**(converter)  | 데이터 처리 **전에 스키마(형식)를 변경**          | `JsonConverter` · `StringConverter` · `ByteArrayConverter` · 커스텀 |
| **트랜스폼**(transform) | 각 **메시지 단위로 간단히 변환**(특정 키 삭제·추가 등) | `Cast` · `Drop` · `ExtractField` 등                               |
- **컨버터**: 토픽에 넣기 전 "이 데이터를 JSON 형식으로" 맞추고 싶을 때.
- **트랜스폼**: JSON 데이터에서 "비밀번호 필드만 빼고(Drop)" 보내고 싶을 때.

### 분산 모드 커넥트
![[Pasted image 20260726113359.png|528]]
2대 이상의 프로세스가 1개 그룹(동일 `group.id`)으로 묶여 클러스터처럼 운영. 
1개 프로세스에 이슈가 생겨 종료돼도 남은 프로세스가 커넥터를 이어받아 파이프라인을 지속한다
상용 환경은 최소 2대 이상
