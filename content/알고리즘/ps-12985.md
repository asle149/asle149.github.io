풀이:
1) 
```java
class Solution
{
    public int solution(int n, int a, int b)
    {
        int ans = 0;
        while(a != b){
            a = (a+1)/2;
            b = (b+1)/2;
            ans++;
        }
        return ans;
    }
}
```

2) 비트 연산 - 흥미로운 풀이
- `a - 1`, `b - 1`을 쓰는 이유: 참가자 번호를 0번부터 시작하는 구역 번호처럼 보기 위해서
- 2진수 앞쪽에서 갈라지는 위치가 빠를수록 더 늦게 만남
- `(a - 1) ^ (b - 1)`는 두 번호가 어느 자리에서 다른지 보여줌
- 그 결과의 2진수 길이가 곧 만나는 라운드
```java
class Solution
{
    public int solution(int n, int a, int b)
    {
        return Integer.toBinaryString((a - 1) ^ (b - 1)).length();
    }
}
```
