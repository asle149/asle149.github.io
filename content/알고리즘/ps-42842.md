풀이:
```java
class Solution {
    public int[] solution(int b, int y) {
        int[] ans = new int[2];
        
        for(int h=1; h*h<=y; h++){
            if(y%h == 0){
                int w = y/h;
                if(b == w*2 + h*2 + 4){
                    ans[0] = w+2;
                    ans[1] = h+2;
                    break;
                }
            }
        }
        
        return ans;
    }
}
```
