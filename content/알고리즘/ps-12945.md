풀이:
```java
import java.io.*;
import java.util.*;

class Solution {
    static int DIV = 1_234_567;
    
    public int solution(int n) {
        int[] dp = new int[100001];
        dp[0] = 0; dp[1] = 1;
        for(int i=2; i<=n; i++){
            dp[i] = (dp[i-2]+dp[i-1])%DIV;
        }
        
        return dp[n];
    }
}
```
