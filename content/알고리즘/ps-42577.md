풀이:
사전순 정렬하면 어떤 번호의 접두어는 반드시 바로 앞에 오므로 인접 쌍만 비교하면 된다(사이에 낀 문자열도 같은 접두어로 시작할 수밖에 없기 때문)

```java
import java.util.*;

class Solution {
    public boolean solution(String[] pb) {
        Arrays.sort(pb);
        for(int i=0; i<pb.length-1; i++){
            if(pb[i+1].startsWith(pb[i])) return false;
        }
        return true;
    }
}
```
