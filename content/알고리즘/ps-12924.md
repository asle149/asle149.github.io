풀이:

1) 완전 탐색
```java
class Solution {
    public int solution(int n) {
        int cnt = 0;
        for(int i=1; i<=n; i+=2){
            if(n%i == 0) cnt++;
        }
        return cnt;
    }
}
```

2) 투포인터
```java
class Solution {
    public int solution(int n) {
        int l = 1;
        int r = 1;
        int sum = 1;
        int ans = 0;
        
        while(r <= n){
            if(sum == n){
                ans++;
                sum -= l;
                l++;
            }else if(sum < n){
                r++;
                sum += r;
            }else{
                sum -= l;
                l++;
            }
        }
        
        return ans;
    }
}
```
