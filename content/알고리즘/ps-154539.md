단순 완탐으로 푸니 시간 초과가 났다..
```java
import java.io.*;
import java.util.*;

class Solution {
    public int[] solution(int[] nums) {
        int[] arr = new int[nums.length];
        for(int i=0; i<nums.length; i++){
            int big = -1;
            for(int j=i; j<nums.length; j++){
                if(nums[i]<nums[j]){big = nums[j]; break;}
            }
            arr[i] = big;
        }
        
        return arr;
    }
}
```

Stack으로 푼다는 것은 알았는데 해법을 생각하는 게 어려웠다
while로 시간을 줄였다
```java
import java.io.*;
import java.util.*;

class Solution {
    public int[] solution(int[] nums) {
        Stack<Integer> st = new Stack<>();
        int[] arr = new int[nums.length];
        Arrays.fill(arr, -1);
        st.push(0);

        for(int i=1; i<nums.length; i++){
            while (!st.isEmpty() && nums[st.peek()] < nums[i]){
                arr[st.pop()] = nums[i];
            }
            st.push(i);
        }
        
        return arr;
    }
}
```
